# Sahabdeen Mohammed Dilsath (SMD) - Full Stack Developer Portfolio

Professional portfolio web application showcasing full-stack development projects, relational database architectures, and digital experiences.

## Overview

This portfolio serves as an interactive showcase of practical software development capabilities, frontend engineering, backend integrations, and interface design. Built with modern web standards, it delivers a responsive and accessible user experience across all devices.

## Core Competencies

- Frontend Engineering: React, Next.js, JavaScript, HTML5, CSS3, Tailwind CSS
- Backend Systems: PHP, RESTful APIs, Node.js, Express.js
- Database Architecture: MySQL, Relational Database Design, SQL Query Optimization, Role-Based Access Control
- Tooling and Deployment: Git, GitHub, Vercel, Netlify, Firebase
- Additional Focus Areas: AI Feature Integration, Application Security (CLLMSP, CAPIJ)

## Featured Projects

### StudyBuddy AI
An intelligent notes summarization and active-recall quiz generation web application built with Next.js, React, and Firebase Authentication. Supports in-memory document parsing (PDF, DOCX, TXT) and structured study workflows.

### Lawyers for Minority Rights (LMR) Directory
A legal directory web platform supporting trilingual localization (English, Tamil, Sinhala) and district-based filtering across all 25 districts of Sri Lanka.

### Solace Family Villa
A hospitality website concept with interactive accommodation presentation, property showcases, and direct guest inquiry handling.

### University Learning Management System (LMS)
An academic coursework software system featuring normalized relational MySQL schemas, module management, timetable scheduling, and role-based access control for students and faculty.

## Architecture and Key Highlights

- Floating WebGL Scene: Interactive Three.js 3D core with hardware-accelerated rendering and fluid touch controls.
- Responsive Design: Custom CSS design system optimized for mobile viewports, tablets, and desktop resolutions with zero horizontal overflow.
- Dillu Virtual Assistant: Client-side portfolio co-pilot designed to assist visitors with developer information and project inquiries.
- Direct Document Access: Direct curriculum vitae download in PDF format.
- Interactive Estimator: Dynamic project scoping and quotation enquiry workflow integrated with WhatsApp and email dispatch.

## Getting Started

### Prerequisites

- Node.js (version 18 or later recommended)
- npm or equivalent package manager

### Installation

Clone the repository and install project dependencies:

```bash
git clone https://github.com/Dilsath0512/my-portfolio.git
cd my-portfolio
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the project for production deployment:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deployment

This project is configured for automated continuous deployment on Vercel.
